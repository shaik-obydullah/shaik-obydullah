## 🚀 Featured Projects

### 🏭 [ERP System](https://github.com/shaik-obydullah/erp-system)

AI-powered full-stack ERP and multi-vendor marketplace system. Laravel 13 API,
standalone React 19 POS terminal, Blade/Vue storefront, self-hosted AI (Ollama),
and ML-driven business intelligence with predictive analytics.

**Tech:** Laravel · PHP 8.3 · React 19 · Vue 3 · MariaDB · Docker · Ollama · Flask/scikit-learn

### 🛰️ [BRAC Migration & Reintegration MIS](https://github.com/shaik-obydullah/brac-mis)

Management Information System built for BRAC to track the complete lifecycle of
migrant workers — from at-risk beneficiaries and deployed migrants to returnees
moving through reintegration. RBAC, full audit trail, CSV/Excel/PDF exports,
public job board, and a Sanctum-secured REST API.

**Tech:** Laravel 13 · Blade · Tailwind CSS 4 · MySQL · Redis · Docker

### 🍽️ [Obydullah Restaurant POS Lite](https://github.com/shaik-obydullah/obydullah-restaurant-pos-lite-wordpress-plugin)

Complete restaurant Point of Sale plugin for WordPress with inventory, order
management, and sales tracking. Dine-in / takeaway / pickup orders, invoice
printing, and accounting — available on the [WordPress Plugin Directory](https://wordpress.org/plugins/obydullah-restaurant-pos-lite/).

**Tech:** WordPress · PHP · MySQL · AJAX
